# インストール後の任意の招待取り込み

[English](installer-invites.md)

保存したスクリプトを対話端末で実行し、インストールが成功すると、任意の招待取り込みを案内します。
Enter で省略できます。貼り付けだけでは送信しません。続く非表示の確認入力で、正確に `y` と答えた場合だけ取り込みます。
Enter・EOF・`n`・`yes`・その他の返答は省略します。不明な文字列も同じ確認を通るため、URL の表記や空白で確認を回避できません。

確認文は、固定版 0.10.1 の動作を説明します。

- 通常のトークン（長い `/i` リンクと `acp://invite` 形式を含む）はローカルに保存するだけで、接続を作りません。
- 短い `/j`・`sealbridge://join` リンクは中継器へ通信し、リンクを消費し、接続への同意に署名して招待者へすぐ接続要求を送ります。
  接続は保留のままの場合があります。作業の許可は別です。

`sealbridge@0.10.1` / `sealbridge-local@0.10.1` の固定は維持します。
省略するには `sh install.sh --no-accept` または `& ./install.ps1 -NoAccept` を使います。
CI、標準入出力・標準エラーのリダイレクト、パイプ、端末がない環境でも省略します。
したがって `curl ... | sh` と `irm ... | iex` は質問せずインストールします。
後から自身の端末で `sealbridge accept --paste` を実行するか、保存したインストーラーを対話実行してください。
CLI 単体の `--paste` はインストーラーの非表示入力とは別実装です。CLI は変更していません。

macOS/Linux では標準の3ストリームが端末であり、`/dev/tty` が使える必要があります。
両方の入力を `/dev/tty` からエコーなしで読み、終了・EOF・処理可能な HUP/INT/TERM で元の端末設定を復元します。
シェルのトレース・verbose・自動変数 export が有効な場合は省略します。
外部プロセスの引数にリンクが入らないよう、シェル組み込みの `printf` を必須とします。
SIGKILL など処理不能な終了では、他の端末アプリ同様、後片付けは実行できません。

Windows は保存したスクリプトを Windows PowerShell 5.1 / PowerShell 7 の ConsoleHost で実行します。
`-NonInteractive`、非コンソールホスト、メモリ内実行・パイプは省略します。
両入力に `Read-Host -AsSecureString`（伏せ字）を使います。.NET 内でのみ平文へ変換し、選択済み Node の標準入力へ UTF-8 で渡します。
引数はインストール済みエントリーのパスと `accept --stdin` だけです。PowerShell は平文文字列を保持しません。
子プロセスの出力は読み捨て、終了待ちは60秒に制限します。

インストーラーはリンクを引数・環境変数・履歴・一時ファイル・診断出力に保存しません。
同意後の CLI による通常の鍵・招待の保存は行われます。エラーや相手の情報に機密文字列が含まれる可能性があるため、CLI 出力は表示しません。
取り込み失敗時は固定の `accept --paste` 案内だけを出し、インストール済みファイルと終了状態を維持します。
短いリンクの処理は失敗・中断時も既にリンクを消費したり状態を保存している場合があり、元に戻すものではありません。

## 検証とレビューの証拠

注釈付き `v0.10.1` タグのコミットは、マージ済み準備 PR
[#330](https://github.com/sealbridge/sealbridge/pull/330) の
`f8eac9f5a7b5035b24b1545dd9cfb27e8cefd6bd`、tree は
`a8c3b3d17577146ccd07ee4eee7bfafc006820d8` と一致します。
そのソースの archive、固定 lockfile、`pnpm run package:cli`、`npm pack --ignore-scripts` で作ったローカル tarball を展開して検証しました。
初回調査時に npm の0.10.1は E404、GitHub release は未作成でした。公開物の検証ではなく、ローカルビルドの証拠です。

再現手順は `node scripts/verify-installer-invite-package.mjs /path/to/unpacked/package` です。
合成した署名済みトークン・不正入力・空入力・複数行を、実際のパッケージ CLI の標準入力に渡し、質問もエコーもないこと、有効な入力だけ成功することを確認します。
トークン・長いリンク・ACP URI・2形式の短いリンクは、メモリ内中継器を注入して通信・接続同意の差も確認します。
外部通信は行わず、表示は真偽値・終了状態だけ、使い捨ての保存状態は削除します。

`conformance/installer-invite.test.ts` は POSIX PTY と Windows ConPTY で実際の非表示入力を検証します。
リダイレクト・省略指定・CI・EOF・割り込み時の復元・確認の拒否・失敗も合成データで検証します。
偽の CLI は入力を両出力へ意図的にエコーし、表示が抑止されることを確認します。
Windows は PowerShell 5.1/7 とトレース・トランスクリプトを含みます。
`installer-node.test.ts` は非対話のインストール全体・再実行・ランタイム選択・失敗を検証します。
Installer workflow は Ubuntu・macOS・Windows で両テストとパッケージのインストールを実行します。

ブラウザー動作と [sites.md](sites.md) の約束は維持します。
`/j` の通信・プレビュー API・解析・デプロイ・公開は追加しません。
