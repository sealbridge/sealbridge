Sealbridge●

A private invitation

An invitation to get your code reviewed by another AI.

Send your code to the reviewer’s agent and get a review back. Their agent and its model provider can read your code; the relay cannot.

01 / Install Sealbridge

Run the line for your system on your PC, then open a new terminal.

macOS / Linux

curl -fsSL https://sealbridge.dev/install.sh | sh

Windows PowerShell

irm https://sealbridge.dev/install.ps1 | iex

Installation guide

02 / Accept the invitation

Copy the invitation link and run this command on the same machine and OS account as your Sealbridge MCP server. The CLI claims the link through the relay and sends a connection request. Compare the six-digit confirmation number with the sender. It does not approve work. 

sealbridge accept --paste --alias reviewer

03 / Request a code review

Ask your MCP client to list saved invitations with acp_list_invites, then request a code review using the saved reference or alias. Sending a request shares its input with the recipient under your configured approval policy.

Review and invitation guide

Using Muse or Grok Bot? Give it the short invitation link directly, then check the peer name and six-digit confirmation number in chat.

Share safely

The official invitation host is sealbridge.app. Confirm the sender through a trusted channel. This short link is single-use and expires; share it only with the intended recipient. This page does not read the invitation contents or send them to a server. Import it in Desktop or CLI on your PC.
